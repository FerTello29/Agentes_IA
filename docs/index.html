2.1 Agentes de IA en las TIC

Características

Diseñada para usarse con una mano.

Cada decisión de la interfaz busca que registrar una sesión completa tome el menor número de toques posible.

Cuatro estados de asistencia

Cada participante puede marcarse con un toque.

Asistió Faltó Justificante Suspensión

10 sesiones a un toque

Selector deslizable con fecha y estado de cada sesión. Abre automáticamente la sesión de hoy.

Marcar a todos

Un botón por estado. Ideal para registrar una suspensión de clases completa en un solo paso.

Búsqueda instantánea

Encuentra a cualquier participante por nombre, ID o correo mientras escribes.

Resumen en vivo

Contadores por estado, barra de distribución y anillo con el porcentaje de asistencia.

Sin duplicados ni pérdidas

Clave compuesta sesión + participante, bloqueo con LockService y aviso de cambios sin guardar.

Arquitectura

Del editor al teléfono.

Sin servidores externos ni bases de datos adicionales: todo corre sobre Google Apps Script y Google Sheets.

Agente de IA Propone y revisa el código
VS Code Git → GitHub · clasp → Apps Script
Apps Script Backend y publicación web
Google Sheets Participantes · Sesiones · Asistencias
Web App Interfaz móvil vía google.script.run

clasp push / pull sincroniza el código con Apps Script; git push / pull sincroniza el historial con GitHub. Node.js solo se usa para ejecutar clasp; no hospeda la aplicación.
